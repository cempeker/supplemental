Supplemental Material for ``Robust recalibra5on of aggregate probability forecasts using meta- beliefs” by Cem Peker and Tom Wilkening.


This document provides a guide to the supplemental material, which includes the data sets and R source ﬁles to replicate the results in the manuscript “Robust recalibra:on of aggregate probability forecasts using meta-beliefs” by Peker and Wilkening.

Results are generated using R version 4.3.1 and RStudio Version 2023.06.2+561. It is suﬃcient to run the commands in recalibr_analysis.R in order to reproduce all ﬁgures and tables in the paper.

Unzip the supplemental material folder, open recalibr_analysis.R and run the commands in order. The working directory should be the same directory as recalibr_analysis.R. This is set by default if RStudio is launched by opening recalibr_analysis.R. Inline comments in recalibr_analysis.R provide more informa:on on how the codes should be run and results produced by each command. Tables and sta:s:cal results are printed on the console. Figures are saved as pdf ﬁles in the ﬁgures folder.


recalibr_analysis.R

Includes the R scripts to reproduce all the tables, ﬁgures and sta:s:cal results in the manuscript. Inline comments in recalibr_analysis.R provide informa:on on how the codes should be run and the results produced by each command. Reads recalibr_dataset.csv from the data folder.


recalibr_dataset.csv

Constructed combining the raw data from Wilkening et al. (2022) and Howe et al. (2024).

Variables:

  • task_type: “Science”, “States”, “Artwork” or “NFL”.

  • item: Unique iden:ﬁer for the task

  • subject: Subject ID (not unique across task types)

  • prob: Probability predic:on, between 0 and 1

  • metaprob: Metapredic:on on average prob in that task, between 0 and 1

  • binary_outcome: Correct answer (binary), 0: False/No, 1: True/Yes


    construct_dataset.R

    Constructs recalibr_dataset.csv using the raw data from Wilkening et al. (2022) and Howe et al. (2024). Reads raw data from data/rawdata folder. The output (recalibr_dataset.csv) is saved in data/recalibr_dataset.csv. This script does not have to be run for reproducing the results, the output (recalibr_dataset.csv) is already included in the Data folder. Running this script overwrites data/recalibr_dataset.csv.

    Data folder

    Includes the data set recalibr_dataset.csv constructed from raw data and two subfolders which include raw data. More informa:on on the raw data below.


    Rawdata subfolder in Data

    Includes two subfolders “wilkening2022” and “howe2024”, which provide the raw data.

    Files in wilkening2022:

  • r2a_rawdata.csv, r2b_rawdata.csv, r2c_rawdata.csv, r2d_rawdata.csv, r2e_rawdata.csv:

    Responses to “Science” tasks, collected over 5 samples.

  • r2_outcomes.csv: Ques:ons and binary truths for the Science tasks

  • m4data.csv: Responses to “States” tasks

  • m4data_details.csv: Ques:ons and binary truths for the States tasks

  • See Wilkening et al. (2022) for more informa:on.

    Files in howe2024:

  • mwh_data.csv: Data from Howe et al. (2024). Pr_forecast and Meta-PredicDon provide the predic:on and meta-predic:on data.

  • mwh_QuesDonsList.csv: Ques:ons and binary truths for the tasks in the Howe et al. (2024) data.

  • Subfolder artwork: Drawings that par:cipants predict the market value of in the Artwork tasks (Howe et al., 2024).

  • See Howe et al. (2024) for more informa:on.
